# @claude-code/workflows

Collection of Claude Code workflows for the Context Engineering Template.

## Overview

This package contains 4 specialized workflows that orchestrate complex development processes.

## Available Workflows

### Development Lifecycle Workflow
- Comprehensive development process orchestration
- Integrates with SDLC Pipeline System
- Manages phase transitions and quality gates

### Quality Assurance Workflow
- Automated quality checks and validation
- Code review and security assessment
- Performance and test coverage validation

### PRD Lifecycle Workflow
- Product Requirements Document management
- From creation to implementation tracking
- Automatic SDLC integration

### Document Management Workflow
- Bilingual documentation synchronization
- Automatic validation and updates
- Knowledge base maintenance

## Usage

Workflows are automatically available in Claude Code when the Context Engineering Template is initialized.

## Integration

Workflows integrate with:
- 26 AI agents for task execution
- 26 commands for specific operations
- SDLC Pipeline System for lifecycle management
- PRD system for requirements tracking
