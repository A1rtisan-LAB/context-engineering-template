# @claude-code/agents

Specialized AI agents for Claude Code development tasks.

## Available Agents

This package contains 22 specialized agents for different development scenarios:

### Analysis Agents
- `architecture-analyzer` - Analyze software architecture and design patterns
- `code-quality-analyzer` - Analyze code quality and maintainability
- `performance-analyzer` - Analyze performance bottlenecks and optimization opportunities
- `security-analyzer` - Analyze security vulnerabilities and best practices

### Implementation Agents
- `feature-implementer` - Implement new features with intelligent persona activation
- `code-enhancement-specialist` - Systematic code improvements and refactoring
- `code-cleanup-optimizer` - Clean up codebase and remove dead code

### Support Agents
- `concept-explainer` - Explain code functionality and programming concepts
- `issue-diagnostician` - Diagnose and resolve technical issues
- `dev-estimator` - Provide development time estimates

### Workflow Agents
- `git-workflow-manager` - Manage Git operations intelligently
- `task-orchestrator` - Coordinate complex multi-step tasks
- `workflow-orchestrator` - Execute cross-session persistent workflows
- `test-execution-manager` - Run and manage test suites

### Documentation Agents
- `focused-doc-generator` - Create targeted documentation
- `project-knowledge-curator` - Maintain project knowledge bases

### Specialized Agents
- `system-architect` - Design system architecture and APIs
- `build-packager` - Build and package software projects
- `prd-workflow-generator` - Transform PRDs into implementation workflows
- `project-context-analyzer` - Understand project structure and dependencies
- `agent-prompt-reviewer` - Evaluate agent prompt quality
- `claude-code-structure-auditor` - Audit Claude Code project structure

## Installation

```bash
npm install @claude-code/agents
```

## Usage

Agents are automatically loaded by Claude Code when this package is installed in your project.
