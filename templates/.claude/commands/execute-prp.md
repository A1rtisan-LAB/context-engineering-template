# Execute PRP Command

이 파일의 내용을 읽고 다음 작업을 수행하세요:

1. **PRP 파일 읽기**
   - 제공된 PRP 파일 경로: $ARGUMENTS
   - 모든 섹션을 주의 깊게 읽기

2. **구현 계획 수립**
   - PRP의 구현 단계를 따라
   - 작업을 작은 단위로 분해
   - 우선순위 결정

3. **단계별 구현**
   각 단계마다:
   - 코드 작성
   - 파일 생성/수정
   - 즉시 테스트
   - 문제 발견 시 수정

4. **검증 수행**
   - 각 검증 게이트 통과 확인
   - 테스트 실행
   - 코드 품질 검사

5. **완료 확인**
   - 모든 성공 기준 충족
   - 문서 업데이트
   - TASK.md에 완료 표시

중요: CLAUDE.md의 모든 규칙 준수
