# Check Quality Command

코드 품질을 종합적으로 검사합니다:

1. **규칙 준수 확인**
   - CLAUDE.md 규칙 체크
   - 파일 크기 제한
   - 명명 규칙

2. **코드 품질 메트릭**
   - 복잡도 분석
   - 중복 코드 탐지
   - 의존성 분석

3. **문서화 상태**
   - README 최신화 여부
   - 함수 문서화
   - 인라인 주석

4. **보안 검사**
   - 민감 정보 노출
   - 보안 취약점
   - 의존성 취약점

5. **개선 제안**
   - 우선순위별 정리
   - 구체적인 액션 아이템
   - 참고 자료

문제점과 개선 사항을 우선순위별로 정리하세요.
