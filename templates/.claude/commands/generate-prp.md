# Generate PRP Command

이 파일의 내용을 읽고 다음 작업을 수행하세요:

1. **$ARGUMENTS 파일 읽기**
   - 제공된 INITIAL 파일 경로: $ARGUMENTS
   - 파일 내용을 완전히 이해

2. **코드베이스 탐색**
   - 프로젝트 구조 파악
   - examples/ 폴더의 패턴 분석
   - CLAUDE.md의 규칙 확인

3. **관련 정보 수집**
   - 필요한 문서 URL 수집
   - 관련 기술 스택 조사
   - 모범 사례 확인

4. **PRP 생성**
   - PRPs/templates/prp_base.md를 기반으로
   - PRPs/[feature-name].md 파일 생성
   - 모든 섹션을 상세히 작성

5. **품질 검증**
   - 구현 단계가 명확한가?
   - 필요한 컨텍스트가 모두 포함되었는가?
   - 성공 기준이 측정 가능한가?
   - 신뢰도 점수 (1-10) 부여

목표: 포괄적인 컨텍스트를 통한 원패스 구현 성공
