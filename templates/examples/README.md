# 예시 코드 설명

이 폴더는 프로젝트에서 따라야 할 코드 패턴과 베스트 프랙티스를 포함합니다.

## 폴더 구조

### _patterns/
공통 코딩 패턴 문서
- `error-handling.md` - 에러 처리 패턴
- `testing.md` - 테스트 작성 패턴
- `validation.md` - 입력 검증 패턴

### architecture/
시스템 아키텍처 패턴 예시
- 클린 아키텍처
- MVC 패턴
- 도메인 주도 설계

### api/
API 구현 패턴
- REST API
- GraphQL
- WebSocket

### database/
데이터베이스 관련 패턴
- ORM 사용법
- 마이그레이션
- 쿼리 최적화

### tests/
테스트 작성 패턴
- 단위 테스트
- 통합 테스트
- 목(Mock) 사용법

## 사용 방법
1. 관련 패턴을 찾아 참고
2. 직접 복사하지 말고 프로젝트에 맞게 수정
3. 패턴의 원칙을 이해하고 적용

## 주의사항
- 예시는 참고용이며 그대로 사용하지 마세요
- 프로젝트 요구사항에 맞게 수정하세요
- 더 나은 패턴이 있다면 개선하세요
