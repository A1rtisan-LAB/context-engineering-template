# Claude Code 실행 시 문제 해결

## 일반적인 문제와 해결방법

### 1. 커맨드가 인식되지 않음
- `.claude/settings.json` 파일 확인 (`.local` 아님!)
- JSON 문법 오류 확인
- 파일 경로가 정확한지 확인

### 2. 파일을 찾을 수 없음
- 작업 디렉토리가 프로젝트 루트인지 확인
- 파일 경로에 오타가 없는지 확인
- 대소문자 구분 확인 (리눅스/맥)

### 3. $ARGUMENTS 변수 문제
- 커맨드 파일에서 $ARGUMENTS 사용 확인
- 인자를 올바르게 전달했는지 확인

### 4. 메모리/성능 문제
- 큰 파일은 분할하여 처리
- 불필요한 파일 제외
- 컨텍스트 창 관리

## Claude Code 최적화 팁

1. **명확한 지시**
   - 구체적인 파일 경로 사용
   - 단계별 작업 요청

2. **컨텍스트 관리**
   - 관련 파일만 열어두기
   - 큰 파일은 요약본 준비

3. **점진적 개발**
   - 작은 기능부터 시작
   - 자주 테스트하고 검증

4. **백업**
   - 중요한 변경 전 커밋
   - 실험적 기능은 브랜치에서

## 자주 발생하는 에러

### "명령을 찾을 수 없습니다"
```bash
# 해결: 경로 확인
ls .claude/commands/
cat .claude/settings.json
```

### "파일 생성 실패"
```bash
# 해결: 권한 확인
chmod -R 755 .
```

### "테스트 실패"
```bash
# 해결: 의존성 확인
pip install -r requirements.txt  # Python
npm install  # Node.js
```
