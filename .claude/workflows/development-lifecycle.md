# Development Lifecycle Workflow

## 🔄 V2 Context Engineering Development Cycle

### Complete Feature Development Workflow
Execute this sequence for comprehensive feature implementation with quality assurance:

```bash
# Phase 1: Analysis & Planning
/analyze:project-context .                  # Understand current system state
/analyze:architecture .                     # Assess architectural impact
/analyze:code-quality .                     # Establish quality baseline
/support:estimate [feature-implementation] # Accurate timeline estimation

# Phase 2: Implementation
/implement:feature [core-functionality]    # Primary feature development
/implement:enhancement [integration-points] # System integration improvements
/implement:cleanup [affected-modules]      # Code quality optimization

# Phase 3: Quality Assurance
/analyze:security [new-components]         # Security vulnerability assessment
/analyze:performance [performance-impact] # Performance regression testing
/manage:test [comprehensive-test-suite]   # Automated test execution

# Phase 4: Documentation & Deployment
/support:document [feature-documentation] # Automated documentation generation
/manage:git [semantic-versioning]         # Version control with proper commits
/manage:build [production-deployment]     # Build and deployment orchestration
```
