# Project Context Memory

## Project Architecture Patterns
- Follow domain-driven design with clear bounded contexts
- Implement microservices architecture with service mesh integration
- Use event-driven communication between services
- Apply CQRS pattern for read/write separation where beneficial

## Code Quality Standards
- Maintain minimum 85% test coverage with comprehensive test suites
- Follow clean code principles with readable, maintainable implementations
- Apply SOLID principles and design patterns appropriately
- Use static analysis tools and automated code quality checks

## Performance Requirements
- Target response times under 200ms for 95th percentile
- Design for horizontal scalability from day one
- Implement caching strategies at appropriate layers
- Monitor and optimize database query performance

## Security Guidelines
- Apply zero-trust architecture principles
- Implement defense-in-depth security strategies
- Use secure coding practices and vulnerability scanning
- Follow OWASP security guidelines and compliance requirements

## Development Workflow
- Use feature branch workflow with pull request reviews
- Apply semantic versioning for releases
- Maintain comprehensive documentation and API specs
- Follow infrastructure as code practices
